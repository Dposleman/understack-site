# Search Console and Local SEO Setup

## Google Search Console

1. Open Google Search Console and add `understack.dk` as a Domain property.
2. Verify with DNS TXT record through the domain DNS provider.
3. After verification, submit `https://understack.dk/sitemap.xml`.
4. Request indexing first for:
   - `https://understack.dk/dk/`
   - `https://understack.dk/dk/webudvikling-aarhus`
   - `https://understack.dk/dk/softwareudvikling-aarhus`
   - `https://understack.dk/dk/webudvikling`
   - `https://understack.dk/dk/softwareudvikling`
   - `https://understack.dk/dk/restaurant-software`
   - `https://understack.dk/dk/cases/gastroapp`
5. Review Pages, Sitemaps, Experience and Enhancements weekly during the first month.

Do not add fake verification codes. If meta verification is preferred later, add the real token to `index.html` or an environment-driven injection step.

## Bing Webmaster Tools

1. Add `understack.dk`.
2. Import from Google Search Console if available, or verify with DNS.
3. Submit `https://understack.dk/sitemap.xml`.

## Google Business Profile Checklist

Recommended setup:
- Category: Software company
- Secondary services: Web designer, Software company, Website designer, Business development service if accurate
- Description: Use the real UnderStack positioning from `/dk/`
- Website: `https://understack.dk/dk/`
- Service area: Aarhus first, then Denmark if accurate
- Images: logo, founder/team images if real, product screenshots, workspace images only if real
- Reviews: ask legitimate customers after completed work; never create fake reviews

Needed from owner:
- Public address or service-area-only preference
- Public phone number, if any
- Opening/contact hours, if any
